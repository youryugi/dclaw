# 梯度辅助粒子滤波：可行性评估

研究问题：利用 `differentiable_dclaw/`（JAX 版 D-Claw）提供的精确梯度，能否**减少粒子滤波所需粒子数**，
并**缓解 particle degeneracy（权重退化）**？

结论先行：**原理上可行，且有成熟文献支撑；但在本模型 + Montecito 这类数据上，收益被几个具体因素
限制，"用梯度减少粒子数" 能否成立必须用"等计算预算下的 ESS"来证明，不能默认成立。**

---

## 1. 为什么原理上可行

权重退化的根源：proposal（通常是先验）和后验差得太远。观测越多、越精确，似然越尖锐，
需要的粒子数随"有效观测维数" τ² 指数增长（Snyder et al. 2008；Bengtsson, Bickel & Li 2008：
N ~ exp(τ²/2)）。梯度 ∇log p(y|θ) 正好告诉每个粒子"往哪走能提高似然"，可以把粒子推向后验，
从而降低权重方差。已有的成熟做法：

| 方法 | 梯度用在哪 | 是否保持精确后验 | 备注 |
|---|---|---|---|
| Laplace / Gauss-Newton proposal | 用 JᵀR⁻¹J 构造以 MAP 为中心的高斯 proposal，再做重要性加权 | 是（权重修正） | 最简单的基线；本仓库已有 Gauss-Newton |
| 回火 SMC + MALA/HMC 移动核 | 每个回火阶段用梯度 MCMC 移动粒子 | 是 | **最稳健、首选** |
| Implicit PF（Chorin & Tu 2009） | 每个粒子做一次优化找高概率区 | 是（需 Jacobian 行列式） | 高维时行列式昂贵 |
| Particle flow（Daum–Huang）/ SVGD / Mapping PF（Pulido & van Leeuwen 2019） | 用梯度确定性地"流动"粒子 | 通常近似（有偏） | 粒子数少时效果好，但要注意方差低估 |
| 似然信息子空间 LIS / active subspace | 用梯度的 Gauss-Newton Hessian 找出"数据真正约束的方向" | 是 | 对本项目可能**最有价值**，见 §3.2 |

注意区分：文献里的 "differentiable particle filter"（Corenflos et al. 2021 等）是**对滤波器本身求导**
来学习参数，和"用模型梯度改进 proposal"是两件事。本研究是后者。

---

## 2. 本项目已有的有利条件

- 梯度可信：全程 1800 s 真实地形 rollout，autodiff 与有限差分吻合 6–7 位有效数字；
  25,787 维观测向量的方向导数余弦 = 1.000（`differentiable_dclaw/README.md`，第 11 项）。
- 算得起：GPU 上一次正演 ~0.7 s；对全部 23,600 个网格参数的反向梯度 ~6–7 s（checkpoint）；
  对 2–3 个标量参数用 `jax.jacfwd` 约为 (p+1) 次正演的代价。
- 已有 Gauss-Newton 标定（`validation/montecito_realterrain_crosscheck/calibrate.py`），
  可直接作为 Laplace proposal 的起点。

## 3. 客观的限制（这是决定成败的部分）

### 3.1 Montecito 数据不是时间序列 —— "滤波"其实是一次性贝叶斯更新
可用观测（淹没范围、建筑物处峰值深度、峰值深度剖面）都是**事后静态**数据。没有逐时刻到达的观测，
就没有"序列"可滤，粒子滤波退化成**单步重要性采样**，而单步 IS 恰恰是退化最严重的情形。
正确的框架是 **SMC sampler（似然回火）**，梯度用于每一步的 MCMC 移动。
若想做真正的序列同化，需要有时间序列的数据：USGS 水槽实验（`validation/usgs_flume_*`，有深度和
基底孔压时程）更合适。JAX 求解器现已支持移动闸门（`solver.gate_bed`，与 Fortran 的 dtopo 表示一致，
见 `differentiable_dclaw/tests/test_gate.py`），并已在水槽算例上与 Fortran 做了相同输入的交叉对比
（`flume_crosscheck/README.md`）。结论：修正包内的 α 下限后，孔压和测点流深时程与 Fortran 接近；
陡坡上 Audusse 重构的薄层误差用加密网格（建议 0.03125 m，约 44 s/次）压低。质量损失 JAX 8% 与 Fortran 7% 相当。
`flume_solver.py` / `check_dry_tol.py` 的阈值结论（降低阈值会使梯度失效）是在修正前测的，方向不变：
做梯度相关的工作保持 1 mm。

### 3.2 可辨识性差：大部分方向上似然是平的
仓库自己的测量（`identifiability.py`、twin 实验）：
- kref 在 1e-13 ~ 1e-10.5 m² 之间对剖面数据几乎不敏感；
- φ 的敏感度仅 0.006/度（流体几乎处处液化，σₑ≈0，摩擦 ≈ 0）；
- 23,600 维场参数的 twin 反演中，φ 场和床面修正场都**没有**被恢复。

后果：
- **标量参数（2–5 个）情形**：维数低，普通 PF/IS 用几百~几千个粒子本来就不贵
  （1000 粒子 × 0.7 s ≈ 12 分钟 GPU，还能 vmap 批处理）。梯度能减少粒子数，但省下的绝对计算量有限，
  而每个"梯度粒子"要花 3–10 次正演的代价。**必须按等计算量比较。**
- **高维场参数情形**：退化只发生在数据真正约束的少数方向上，其余方向后验≈先验。
  这时梯度最有价值的用法不是"推粒子"，而是**用 Gauss-Newton Hessian 找出低维似然信息子空间（LIS）**，
  只在子空间里做 PF/SMC、补空间按先验采样。这样才可能把粒子数降几个数量级，而且是有理论保证的。

### 3.3 似然面不光滑、可能多峰 —— 梯度只是局部信息
README 已记录：kref ≈ 1e-10.45 附近存在 **regime switch**（长距离流出）；部分位置**双稳态**
（堆积叶瓣形成与否，±0.2–0.3 m）；缓慢蠕动堆积有 ~1e-4 m 的台阶结构，Gauss-Newton 需要平滑 Jacobian。
- 梯度是**精确的**，但那是一个分段光滑函数的局部导数，跨不过 regime 边界。
- 纯梯度流（SVGD/particle flow）会把粒子全拉进同一个模态，**恰好丢掉 PF 最大的优势——表示多峰后验**。
- HMC/MALA 在不光滑处接受率会下降，需要小步长。
所以设计上必须保留全局探索（回火 + 足够的初始粒子 + 精确的 MH 修正），梯度只做局部加速。

### 3.4 相当一部分"退化"来自模型误差，而不是粒子太少
真实地形上 CSI 仅 ~0.5，西南叶瓣始终到不了（Fortran 与 JAX 相同，结构性问题）。
如果似然用的观测误差只反映测量误差，那么所有粒子都离观测很远，权重由少数"错得最少"的粒子支配——
这种退化增加粒子或加梯度都治不好，而且梯度会把粒子推向一个**有偏**的后验。
需先建立合理的误差模型（模型偏差项、空间相关误差或回火/膨胀），再谈粒子数。

## 4. 判断

| 说法 | 评价 |
|---|---|
| 梯度可以缓解权重退化 | **成立，已在水槽 twin 实验中验证**（`pf_flume/`）：先验 IS 4096 粒子 ESS = 1–2；梯度（Gauss-Newton）构造的提议 1024 粒子 ESS 435–547。按时间同化（IBIS）时，Gauss-Newton 独立提议消除了随机游走移动造成的粒子贫化（后者低估不确定度约 10%），且快 1.8 倍 |
| 梯度方法比最常用的不用梯度方法更快 | **不成立，需要修正说法**（`pf_flume` 第六轮）：集合卡尔曼方法 ES-MDA 与梯度方法耗时同一量级（甚至更快），但它的后验只是线性高斯近似——单峰时不确定度宽 1.2–2 倍，双峰时几乎只剩一个峰，7 维弯曲山脊上均值偏 2–6 sd；加到 K = 16 或 N = 2048 仍达不到（单峰时 K = 16 才接近梯度方法，耗时已是其 2.5 倍）。梯度方法的优势是**同等成本下后验准得多**；相对精确但昂贵的回火 SMC，则是准确度相当时快 2–8 倍 |
| 梯度可以减少所需粒子数 | **成立，但取决于梯度用在哪里**。3 参数实验（5 个种子、3 组噪声、有/无孔压观测）：稳健 Laplace 提议比回火 SMC-RW 快约 5 倍（只观测流深时 1.4–4 倍）；把梯度用在 MCMC 移动（MALA）反而比 RW 慢约 3 倍（一次梯度 ≈13 次前向） |
| 单起点的 Gauss-Newton / Laplace 就够了 | **不成立**：似然有很多局部极小，9 个固定起点只有 2 个到达全局众数。必须先用少量先验样本筛选起点（多起点），并在提议里保留先验成分 |
| 多峰后验下梯度方法仍然占优 | **有条件成立**（`pf_flume` 第三轮）：只测 32 m 流深时后验双峰（B 峰质量 0.447）。起点太少（只取最好的 4 个）时 5 次只有 2 次两峰都找到，漏峰时 P(B) 错到 0.06–0.65 且 ESS 可能仍显示正常；改用 16 个分散起点、批量 Gauss-Newton、只用收敛点后，两峰每次都找到，P(B) 0.41–0.46，比回火 SMC-RW 快 3.6–3.7 倍且更准（修正实现后的用时，见 `pf_flume/README.md`） |
| 维度越高梯度方法优势越大 | **在本问题上不成立**（`pf_flume` 第四轮）：7 个参数时后验是一条弯曲的平山脊（数据只定住 m_crit − m0），Laplace 类方法只快约 1.2 倍（3 维时 5.6–7.8 倍）；用梯度做 MCMC 移动（MALA）的混合效率比随机游走低约 50 倍（一次梯度 ≈ 14 次前向）。反向模式梯度的成本不随参数个数增长，交叉点约 7 个参数；高维要真正受益，需要更便宜的梯度和能适应弯曲几何的方法 |
| 在真实数据上仍然有效 | **方法层面成立**（`pf_flume` 第五轮，2010 USGS 水槽实测）：稳健 Laplace 与回火 SMC-RW 后验一致，快约 3.7 倍，并找到了真实数据下的多个局部众数。但反演会把模型结构误差（模型模拟不出前锋浪涌）吸收进参数：只用上游反演时下游 90 m 预测失败，三个测点一起反演则把参数推到先验边界。稳健性检验（孔压换算、先验范围、AR(1) 时间相关误差、细网格）表明：孔压换算和先验边界都不是原因；网格粗细会使反演出的 φ 相差约 4.4°（粗网格参数在补偿数值误差）；AR(1) 误差让后验变宽、粗网格下预测区间能覆盖 90 m，但细网格下下游堆积又变得太厚——只用上游数据约束不了下游的停积过程。限制预测的是模型（含数值）误差，不是算法 |
| 前提：梯度本身可靠 | 实验前发现并修复了一个模型层面的问题（包 README 第 13 条）：修复前真值附近一半参数点的雅可比爆炸到 1e4–1e19。**任何基于梯度的同化都应先在先验范围内多点核对雅可比** |
| 这是一个新想法 | 通用思路**不新**；新意在于把它落到真实地形、带孔压/膨胀的可微泥石流模型上，并诚实处理 regime switch 与模型误差。有发表价值，但需严谨基准 |
| 直接拿 Montecito 淹没图做"粒子滤波" | **不建议**：数据非序列，且模型结构误差大。先做合成 twin，再上真实数据 |

## 5. 最小验证方案（建议顺序）

1. **合成 twin，低维**（已完成，见 `pf_flume/README.md`）：θ = (φ, log10 kref, log10 alpha_c)，由已知真值生成观测（加噪声）。
   参考后验：大 N（如 2×10⁴）重要性采样或长链 MCMC。
2. **对比方法**（相同 GPU 时间预算）：
   - 基线：先验 proposal 的 bootstrap IS / 回火 SMC（随机游走 MH 移动）
   - A：Gauss-Newton Laplace proposal + 重要性权重
   - B：回火 SMC + MALA（或 HMC）移动
   - C（可选）：SVGD / mapping PF，检验其方差低估
3. **指标**：ESS/N、ESS/GPU 秒、后验均值与 90% 区间覆盖率（对参考后验）、
   跨 regime（真值放在 kref ≈ 1e-10.45 附近）时的表现。
4. **高维扩展**：用 JᵀR⁻¹J 的特征分解估计 LIS 维数 r；若 r ≪ 23,600，做 LIS-SMC。
   这一步决定"减少粒子数几个数量级"的说法是否能成立。
5. **序列同化**（IBIS 已完成，见 `pf_flume/README.md`）：闸门已补上，与 Fortran 的水槽对比已完成（`flume_crosscheck/README.md`）。
   包内已去掉 α 下限（孔压动力学错误、alpha_c 几乎失效；去掉后梯度仍精确，Montecito CSI 0.491→0.488）；
   陡坡薄层问题提供 Chen–Noelle 重构作为选项，但它与可微性冲突，默认仍为 Audusse + 加密网格。
   在 USGS 水槽时程上做逐时刻 PF 时，合成观测应由 JAX 自己生成。

判定标准：若 A/B 在等时间预算下的 ESS 或后验精度**不优于**基线，则该方向在低维问题上不成立，
应把重点转向 LIS（第 4 步）。
