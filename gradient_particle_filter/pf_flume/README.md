# 水槽 twin 实验：梯度能否减少粒子数、缓解权重退化

## 设置

- 模型：`differentiable_dclaw` 包默认（Audusse 重构，无 α 下限，剪胀项 h 下限 2 cm），2010 SGM 闸门释放，
  0.125 m 网格（`flume_model.py`；地形等输入来自 `../flume_crosscheck/fortran_run`，先跑一次 `fortran_setup.py`）。
- 参数 θ = (φ, log10 kref, log10 alpha_c)，真值 = 论文值 (40.7°, 5e-9, 0.024)；先验为均匀盒子
  φ∈[34,46]，log10 kref∈[−10,−7]，log10 alpha_c∈[−2.5,−1]，在 logit 空间采样。
- 观测：x = 2 / 32 / 66 m 三个测点，0.5–12 s 每 0.5 s 的流深与基底孔压，共 144 个数，
  加噪声 σ_h = 1 cm、σ_pb = 0.1 kPa（观测由 JAX 模型自身生成，排除模型误差）。
- 一块 RTX 5000 Ada，float64。前向 ≈0.08–0.12 s/粒子（批量 256），前向+梯度（jacfwd，3 参数）≈1.1 s/粒子。

```
python run_twin.py laplace 1024      # Gauss-Newton 找众数 + 多元 t 提议的重要性采样
python run_twin.py bootstrap 4096    # 从先验直接重要性采样
python run_twin.py smc_rw 512        # 似然回火 SMC，随机游走 MH 移动（5 次/阶段）
python run_twin.py smc_mala 128      # 似然回火 SMC，预条件 MALA 移动（5 次/阶段）
python compare_methods.py            # 与参考后验对比
```

## 结果（种子 0，各跑一次）

| 方法 | 粒子数 | 用时 | 前向 / 梯度 次数 | ESS | 均值偏差（参考 sd） | sd / 参考 sd |
|---|---|---|---|---|---|---|
| bootstrap（先验 IS） | 4096 | 485 s | 4096 / 0 | **1.0** | +1.60 / +0.21 / −0.61 | 0.11 / 0.19 / 0.11 |
| **Laplace IS（梯度）** | 1024 | **147 s** | 1024 / 31 | **547** | 参考 | 1 |
| 回火 SMC + RW | 512 | 1960 s | 23552 / 0 | 512（MCMC） | −0.06 / +0.04 / +0.07 | 0.96 / 0.95 / 0.98 |
| 回火 SMC + MALA（梯度） | 128 | 6516 s | 0 / 5888 | 128（MCMC） | +0.05 / −0.09 / +0.02 | 0.97 / 0.97 / 1.01 |

参考后验：φ = 40.40 ± 0.29，log10 kref = −8.291 ± 0.030，log10 alpha_c = −1.580 ± 0.026
（真值 40.70 / −8.301 / −1.620，均在 1–1.5 sd 内）。三种互相独立的方法与之一致（偏差 < 0.1 sd），参考可信。
两个 SMC 都用了 9 个回火阶段；接受率 RW 0.30、MALA 0.57。

## 结论

1. **退化是真实而严重的**：后验比先验窄 40–100 倍，从先验抽 4096 个粒子 ESS = 1，给出的"后验 sd"小 5–10 倍，完全误导。
2. **梯度最有效的用法是构造全局提议分布**：Gauss-Newton（31 次雅可比）找到众数和曲率，再做重要性采样，
   1024 个粒子 ESS 547，用时 147 s——与 bootstrap 相比，粒子数少 4 倍、时间少 3 倍、ESS 高 500 倍；
   与回火 SMC-RW 相比，时间少 13 倍。**注意**：这个单起点结果依赖起点落在正确的吸引域里（第二轮发现 9 个起点只有 2 个行）；
   稳健版本（筛选 + 多起点）约 360–400 s，比 SMC-RW 快约 5 倍。
3. **梯度用在 MCMC 移动里（MALA）在这里不划算**：一次梯度 ≈13 次前向的代价，接受率只从 0.30 提到 0.57；
   同样精度下 MALA 比 RW 慢约 3 倍（128 粒子 6516 s vs 512 粒子 1960 s）。3 维、近高斯后验里，
   用粒子协方差自适应的随机游走已经足够好。
4. 对"能否减少粒子数并缓解退化"的回答：**在这个问题上能，而且幅度很大——但靠的是 Laplace/Gauss-Newton 提议，
   不是基于梯度的 MCMC 移动。**

## 第二轮：稳健性与按时间同化（`queue.sh`，结果在 `results/<obs>_noise<k>/`）

### 单起点 Laplace 不稳健（`explore.py`）
从先验中心和先验盒子 8 个角点（向内 10%）出发做 Gauss-Newton：**9 个起点只有 2 个到达全局众数**，其余停在
−log 后验 290–970 的局部极小（全局 67.5；只观测流深时全局 39.4，同样 2/9）。kref 剖面在 log10 kref≈−9.5…−9.1
有一串局部极大。第一轮 Laplace 的结果部分是运气——先验中心恰好在正确的吸引域里。

### 稳健版本（`inference.robust_laplace`）
先从先验抽 256 个只算似然，取最好的 4 个做 Gauss-Newton，合并重复众数，用多元 t 混合（+5% 先验防御成分）做提议；
可选地再从提议回火到后验（RW 移动），权重已好时一步到 β=1。所有运行里 4 个筛选起点**全部**到达全局众数。

| 数据 | 方法 | 粒子 | 用时 | IS ESS | 均值偏差 / sd 比（相对 SMC-RW） |
|---|---|---|---|---|---|
| 全部观测，噪声 0 | 稳健 Laplace IS，种子 1–4 | 1024 | 354–406 s | 499–543 | ≤0.13 sd / 0.95–1.01 |
| 同上 | 稳健 Laplace + 回火 | 1024 | 811 s | 519 → 1 阶段 | ≤0.06 / 1.01–1.02 |
| 同上 | 回火 SMC-RW | 512 | 1960 s | — | 参考 |
| 全部观测，噪声 1 | 稳健 Laplace + 回火 / SMC-RW | 1024 / 512 | 786 / 1964 s | 516 | ≤0.13 / 1.01–1.03 |
| 全部观测，噪声 2 | 同上 | 1024 / 512 | 752 / 1941 s | 533 | ≤0.05 / 0.97–1.00 |
| **只观测流深**，噪声 0 | 先验 IS | 4096 | 488 s | **2** | 最大 1.47 / 1.4–1.8 |
| 同上 | 稳健 Laplace + 回火 | 1024 | 1106 s | 435 → 2 阶段 | 0.00 / 1.01–1.04 |
| 同上 | 回火 SMC-RW | 512 | 1563 s | — | 参考 |

- 结论在 5 个采样种子、3 组噪声实现上都成立；稳健 Laplace IS 比回火 SMC-RW 快约 5 倍，代价是比单起点版本慢约 2.5 倍。
- 只观测流深时后验宽约 1.5 倍、形状稍偏离高斯（IS ESS 从 ~520 降到 435，需要 2 个回火阶段），但三个参数仍可辨识，
  方法仍然有效；速度优势缩小到 1.4 倍（带回火）或约 4 倍（只做 IS，ESS 435 已足够）。

### 按时间同化：IBIS（`inference.ibis`，全部观测，噪声 0，N = 512）
观测每 0.5 s 到达一批；ESS < N/2 时重采样并做 MCMC 移动。

| 移动方式 | 重采样-移动次数 | 接受率 | 用时 | 前向 / 梯度 | 最终 sd / 参考 sd |
|---|---|---|---|---|---|
| Laplace 独立提议（梯度，每次 2 步） | 7 | 0.18–0.50 | **980 s** | 7680 / 154 | **0.97 / 0.95 / 1.03** |
| 随机游走（每次 5 步） | 7 | 0.12–0.33 | 1742 s | 18432 / 0 | 0.88 / 0.89 / 0.91 |

- **这是"缓解粒子退化"最直接的证据**：随机游走版每次只在重采样祖先附近做局部移动，粒子虽然各不相同（451/512），
  但整体偏挤，最终不确定度系统性低估约 10%（粒子贫化）；用 Gauss-Newton 构造的独立提议每次都把粒子重新铺满后验，
  sd 正确，且快 1.8 倍。
- 提议从"最可能的粒子"出发做 Gauss-Newton（不是粒子均值）：重采样后粒子已在正确的吸引域里。
- **早期预测**（`analyze_ibis.py`）：只用前 3 s 数据（流动只经过 2 m 测点），预测 66 m 测点到达 7.5–8.5 s（真值 7.5 s，
  在区间边缘）、峰值流深 0.10–0.12 m（真值 0.105 m）；用到 6 s 时 90% 区间包含真值，8 s 时区间收窄到 ±1 mm。
  预测区间只含参数不确定性，不含模型误差。

## 第三轮：真正的双峰问题——稳健 Laplace 的边界

### 构造（`screen_designs.py`、`multistart.py`、`ridge_scan.py`）
只观测 x = 32 m 的流深（野外常见的单测点配置，24 个数，`--obs h@1`）。16 个分散起点的 Gauss-Newton
收敛到两个不同的众数：

| | φ | log10 kref | log10 alpha_c | −log 后验 | 概率质量 |
|---|---|---|---|---|---|
| A | 42.10 | −8.339 | −1.68 | 13.55 | 0.557 |
| B | 42.09 | −8.034 | −2.30 | 14.92 | 0.443 |

两峰之间沿连线升到 15.63（比 B 高 0.7，比 A 高 2.1），是一个浅谷隔开的真双峰：
"渗透率低、压缩性高"和"渗透率高、压缩性低"在 32 m 产生几乎相同的流深时程。
参考后验（`bimodal_reference.py`）：两峰 Laplace 混合 + 5% 先验做重要性采样，8192 个样本，ESS 3342，P(B) = 0.443；
回火 SMC-RW（不用梯度，512 粒子，1180 s）独立得到 P(B) = 0.512（在其 Monte Carlo 误差内），说明没有第三个峰。

### 结果（`queue_bimodal.sh`、`queue_bimodal2.sh`、`bimodal_mass.py`；1024 粒子，筛选 256 个先验样本）

| 方法 | 5 个种子的结果 | P(B) | IS ESS | 用时 |
|---|---|---|---|---|
| 1 个起点 | 全部只找到一个峰 | 0.06 / 0.12 / 0.21 / 0.55 / 0.57 | 52–387（**看起来正常**） | ~220 s |
| 2 个起点 | 1/5 两峰都找到 | 正确的那次 0.465 | — | ~290 s |
| 4 个起点 | 2/5 两峰都找到（0.465 / 0.419 ✓）；3/5 只找到一个峰 + 一个"假众数" | 0.65 / 0.61 / 0.32 ✗ | 正确时 ~420；错误时 **3–19** | ~410 s |
| 1 个起点 + 回火 | 回火只部分补救 | 0.26 / 0.31 / 0.32 | — | ~1350 s |
| 4 个起点 + 回火（1 个种子） | 正确 | 0.525 | — | **1912 s** |
| 回火 SMC-RW（不用梯度） | 正确 | 0.512 | — | **1180 s** |

- **漏峰**：只找到一个峰时，P(B) 可以错到 0.06 或 0.57，后验均值偏移接近 1 个标准差，而 ESS 仍在 50–390，
  **ESS 发现不了漏掉的峰**——粒子全挤在一个峰上，彼此权重反而均匀。
- **"假众数"**：A 附近有一段很平的弯曲山谷，Gauss-Newton 在 40 次迭代内走不到底，停在 [42.2, −8.41, −1.70]
  （−log 后验 13.83）。把这个未收敛点当成一个峰，它的曲率估计是错的，重要性权重随之崩溃（ESS 3–19）。
  这类失败**会**被 ESS 暴露出来，可以据此报警。
- 修正前的合并判据（相距 < 3 个后验 sd 视为同一峰）把 A、B 当成同一个峰合并掉，k = 2、4 与 k = 1 结果几乎相同；
  这批结果保留在 `results/h_1_noise0/before_merge_fix/`。修正后只合并几乎重合（< 0.1 sd）的收敛点。
- **边界（原始稳健版）**：只取最好的 4 个筛选样本作起点时，在这个双峰问题上**不可靠**；靠回火补救的版本比不用梯度的
  回火 SMC-RW 还慢。改进版（见下）解决了这个问题。

### 改进版：分散多起点 + 批量 Gauss-Newton + 只用收敛点（`inference.robust2_laplace`）
- 起点：筛选 512 个先验样本，取似然最高、且彼此相距 ≥10% 先验范围的 16 个（不是简单取最好的几个——那样常常全落在同一个峰）。
- 16 个起点在 GPU 上一起做 Levenberg-Marquardt（一批雅可比约 7.5 s，逐个算要约 17.6 s），最多 40 次迭代
  （实际收敛的起点都在 29 次以内）。
- 只有真正收敛的点（Newton 减量 < 0.05，即离最小值约 0.025，远小于后验 1 sd 对应的 0.5）才进入混合提议；
  都不收敛时退回最低点并警告。阈值取得太严会被目标函数的数值噪声底卡住：1e-8 丢掉了 B 峰，1e-3 在全部观测问题上
  把 16 个已到达众数的起点全部判为未收敛——噪声底随观测数增加而升高。
- 更强的参考（三个极小 A、B、A′ 的混合，放宽 2 倍，10% 先验，16384 样本，`bimodal_reference2.py`）：
  **P(B) = 0.447 ± 0.008**（与第一个参考 0.443 一致；SMC-RW 的 0.512 偏离主要来自其 512 个相关样本的 Monte Carlo 误差）。
  A′（13.833）是 A 旁边一个真正收敛的浅极小。

| 问题 | 改进版结果（5 / 2 个种子） | 用时 | 对比回火 SMC-RW |
|---|---|---|---|
| 双峰（只测 32 m 流深） | 5/5 两峰都找到，P(B) = 0.429 / 0.441 / 0.445 / 0.445 / 0.455，IS ESS 312–429 | 406–506 s | 快 2.3–2.9 倍，且更准（SMC-RW 0.512） |
| 单峰（全部观测） | 16/16 起点收敛，均值偏差 ≤0.08 sd，sd 比 1.00–1.03，IS ESS 535–545 | 349–353 s | 快约 5.6 倍 |

小瑕疵：阈值放宽后，同一个峰附近的几个收敛点有时相距 > 0.1 sd 而未合并（报告 4–7 个"峰"）；它们只是混合里互相重叠的成分，
不影响权重修正后的结果。

### 按时间同化（IBIS）遇到双峰（`queue_ibis_bimodal*.sh`，N = 512，4 个种子）

| IBIS 的移动方式 | P(B)（参考 0.447） | RMS 误差 | 平均用时 | 前向 / 梯度次数 |
|---|---|---|---|---|
| 单峰 Laplace（从最可能粒子做一次 GN） | 0.36 / 0.60 / 0.48 / 0.37 | 0.097 | **687 s** | 4864 / 115 |
| **多峰 Laplace**（16 个分散粒子作起点，批量 GN，收敛峰的混合 + 5% 先验） | 0.48 / 0.43 / 0.49 / 0.38 | **0.045** | 1620 s | 4608 / 1170 |
| 随机游走（5 步） | 0.48 / 0.34 / 0.46 / 0.41 | 0.062 | 1124 s | 11392 / 0 |

- 单峰版的独立提议只覆盖一个峰：另一个峰里的粒子会被"吸"过去，也会被偶然推回，结果波动很大（平均偏差接近 0，但 RMS 0.10）。
- 多峰版最准，但比随机游走慢约 1.4 倍；按 Monte Carlo 误差 ∝ 1/√时间 折算到同等精度，大致持平或略优（只有 4 个种子，结论粗）。
  第一版多峰移动只用 8 个起点、相距 5%，有一次只找到了 A 峰；改成 16 个、相距 10% 后没再出现。
- 慢在梯度：每次重采样都从头对 16 个起点做约 19 次串行的批量 GN 迭代，一次梯度 ≈ 10 次前向的时间
  （理论上 3 个参数的前向模式约 3–4 倍）。小批量、串行的调用吃不满 GPU——瓶颈是调用次数而不是每次算多少，
  所以优化方向是减少串行迭代次数（warm start、更积极的阻尼策略），而不是减少每次的计算量。

### 实现修正后的最终用时（`queue_lm.sh`、`queue_pad.sh`）
两处实现问题让梯度方法之前显得比实际慢，修正后重跑：
1. **阻尼策略太保守**：LM 从 λ = 1e-2、成功 ÷3、失败 ×5 改为 1e-4、÷10、×10（`lm_schedule.py`）；
   双峰问题迭代次数 60+ → 16，单峰 10 → 12 但每次更省时。准确度不变或更好。
2. **重复编译**：批量 Gauss-Newton 在起点陆续收敛时批量大小依次变为 16、15、……、1，JAX 对每个新形状重新编译
   "模型 + 前向模式导数"，每次约 20 s，一次运行最多累计约 300 s（`compile_cost.py`）。随机游走类方法每批固定
   256 个，几乎不受影响——之前的对比对梯度方法不公平。修正：批量补齐到 2 的幂次（`inference._call_padded`）+
   JAX 持久化编译缓存（`run_twin.py`，`.jax_cache/`）。

| 实验 | 梯度方法 | 不用梯度的对照 | 结论 |
|---|---|---|---|
| 静态单峰（全部观测，2 个种子） | 改进版稳健 Laplace **251–347 s** | 回火 SMC-RW 1960 s | 快 **5.6–7.8 倍**，偏差 ≤0.06 sd |
| 静态双峰（只测 32 m，3 个种子） | **316–332 s**，P(B) 0.411 / 0.413 / 0.458 | 回火 SMC-RW 1180 s，P(B) 0.512 | 快 **3.6–3.7 倍**，且更接近参考 0.447 |
| IBIS 双峰（4 个种子） | 多峰 Laplace 移动 1253–1751 s，P(B) 0.417–0.435，**RMS 0.025** | 随机游走 815–1305 s，RMS 0.062 | 单次慢约 1.4 倍；按误差 ∝ 1/√时间 折算到同等精度约快 **4.6 倍**（4 个种子，粗） |

IBIS 多峰版的剩余开销主要是每次重采样后十几次串行的批量 Gauss-Newton 迭代（约 11 s/次）；从上一次的峰出发
（warm start）应能进一步减少。

### 实践建议
1. 永远不要只看 ESS 来判断成功；它发现不了漏峰。
2. 用 Laplace 类方法时，起点要分散（16 个、彼此相距 ≥10% 先验范围），批量运行；只让真正收敛的点进入混合提议，
   收敛阈值要按后验尺度设（Newton 减量 < 0.05），不能用极小的绝对阈值。
3. 用少量回火 SMC 核查一次峰的数量和质量；若与 Laplace 结果不一致，以回火 SMC 为准。
4. 观测设计比算法更根本：同一问题加上 2 m、66 m 测点或孔压测量，双峰就消失了（第一、二轮）。

## 第四轮：7 个参数（`--params 7`，`queue_p7*.sh`、`queue_polish.sh`）

新增 4 个原先当作已知的量：m0（初始固体体积分数，0.55–0.66）、m_crit（0.60–0.68）、p_ratio（初始孔压 / 静水压力，
0.6–1.2）、vol（物源体积倍数，按比例缩放初始料堆厚度，0.8–1.2）；真值 0.62 / 0.64 / 1 / 1。全部观测，噪声 0。
初始状态对 vol 光滑（薄层清零在缩放之前做）。7 维雅可比在整个先验范围内 8 个点、真值附近 8 个点与有限差分吻合
（相对误差中位数 1e-7–1e-4，最大 < 1e-2，`jac_check7.py`）。

**后验是一条长而平的弯曲山脊**：数据定住了 m_crit − m0（≈ 0.019，决定剪缩还是剪胀），却分不清它们各自的绝对值，
它们和 φ、kref 沿山脊互相补偿（16 个 Gauss-Newton 终点的 −log 后验都在 73.40–73.51，φ 从 40.16 到 40.95）。

| 方法 | 用时 | 结果 |
|---|---|---|
| 先验 IS（4096） | 608 s | ESS 1 |
| 稳健 Laplace IS（2 个种子；8192 个也一样） | ~920 s | ESS 10–23 / 1024（23 / 8192）：Gaussian 混合覆盖不了山脊 |
| 同上，沿山脊保留多个分量（merge 0.1 sd） | 906 s | ESS 28 / 1024 |
| 同上 + 回火（RW 移动） | **2320 s** | 4 个回火阶段 |
| 回火 SMC-RW | **2764 s** | 12 个回火阶段 |

- 梯度方法（Laplace + 回火）只快约 **1.2 倍**（3 维时 5.6–7.8 倍）：Laplace 近似不贴合山脊，要靠回火和随机游走修正；
  Gauss-Newton 在平山脊上收敛慢（16 个起点 40 次迭代只有 5–6 个收敛），这一步就要约 900 s。
- **参考后验没能确定**（`mcmc_polish.py`）：两组最终粒子各再做 50 步随机游走后，均值一致（相差 0.1–0.3 sd），
  但 sd 仍各自保持（log10 alpha_c 0.047 对 0.068，m0 0.010 对 0.008）——随机游走在山脊上混合太慢，
  50 步累计的归一化平方跳跃距离（~4）还不到维数 7。
- **反向模式梯度**（`Flume.simulate(scan_steps=...)`，分块 checkpoint，`reverse_cost.py`）：与前向模式一致到 3e-14；
  成本不随参数个数变化（3 个参数 14.0 倍前向，7 个 14.4 倍），前向模式随参数线性增长（6.6 → 12.8 倍），
  **交叉点约在 7 个参数**。固定 5000 步的 scan 本身比按需停止的 while_loop 慢 2.2 倍，这是反向模式开销大的主要原因之一。
- **用梯度做 MCMC 移动在这里不划算**：从同一批后验粒子出发，预条件 MALA（反向模式梯度）每秒的归一化平方跳跃距离
  约 0.0001，随机游走约 0.0053，**差约 50 倍**——一次梯度 ≈ 14 次前向，而弯曲山脊又迫使 MALA 用固定预条件时把步长
  压得很小。理论上 MALA 需要的步数只比随机游走少约 d^(2/3) ≈ 3.7 倍，抵不过单步成本。

**重参数化**（`--params 7d`：用 dm = m_crit − m0 代替 m_crit，dm 先验 [−0.03, 0.08]；注意先验因此与 "7" 不完全相同）：

| | 原参数化（m_crit） | 重参数化（dm） |
|---|---|---|
| 稳健 Laplace IS 的 ESS | 10–28 / 1024 | **69–149 / 1024** |
| Gauss-Newton 收敛起点 | 5–6 / 16 | 9–11 / 16 |
| 稳健 Laplace IS 用时 | ~920 s | 762–814 s |
| 回火 SMC-RW 用时 | 2764 s | 2745 s |

- dm 被数据定得很好（0.019–0.020 ± 0.0015–0.0020，真值 0.02），印证"只定住了差值"。
- 山脊没有消失，换成沿 m0、φ、kref 互相补偿的方向：两种方法在这个方向上的均值相差约 0.4–0.6 sd
  （m0 0.615 对 0.606，φ 40.6 对 40.9）；没有可靠参考，暂不能判断哪个更准。
- 按"只做 IS"计，梯度方法又快了约 3.5 倍，但 ESS 只有 7–15%，可靠性不如 3 维。
- **参考后验**（Δm 参数化）：两种独立方法吻合——稳健 Laplace IS 16384 个样本（2992 s，ESS 339）与回火 SMC-RW
  1024 粒子 × 每阶段 10 步（10704 s）均值相差 ≤ 0.04 sd；山脊方向（φ、m0、Δm）上 IS 的 sd 偏小 10–25%，以 SMC 为准。
  参考：φ 40.48 ± 0.70，log10 kref −8.330 ± 0.151，log10 alpha_c −1.615 ± 0.069，m0 0.620 ± 0.018，Δm 0.0194 ± 0.0024，
  p_ratio 0.991 ± 0.032，vol 1.000 ± 0.010（真值都在 1 sd 内）。

  | 方法 | 用时 | 最大均值偏差 | sd 比 |
  |---|---|---|---|
  | 稳健 Laplace IS，1024（2 个种子） | 762–814 s | 0.22 / 0.44 sd | 0.65–1.07 |
  | 回火 SMC-RW，512 × 5 步（常规） | 2745 s | 0.78 sd | 0.83–1.03 |
  | 稳健 Laplace IS，16384 | 2992 s | 0.04 sd | 0.75–1.04 |
  | 回火 SMC-RW，1024 × 10 步 | 10704 s | 参考 | 1 |

  同量级计算下梯度方法快约 3.5 倍且**均值更准**，但低估山脊方向的不确定度。

  **参考本身的修正**（`ref_check.py`）：用比所有候选都宽的提议（以加长 SMC 的粒子为中心、协方差放大 1.5 倍、
  t 分布自由度 3，另加 5% 先验）做 16384 个样本的 IS（ESS 421；IS 对任何提议都精确，提议更宽只损失 ESS）：
  sd = φ 0.705、m0 0.0182、Δm 0.0021 ± 0.0001。与加长 SMC 在 φ、m0 上一致（0.704、0.0178），但 **SMC 的 Δm
  偏宽约 14%**（0.0024）——回火 SMC 移动不充分时会保留早期较宽的分布。据此，梯度方法（16384 个样本）在山脊方向上
  **低估约 12–20%**（不是 35%）；1024 个样本时个别种子更多。

  修正尝试（Δm 参数化，各 2 个种子，1024 个样本；对照新参考的 m0 / Δm sd 比）：
  | 方法 | 用时 | 最大均值偏差 | m0 sd 比 | Δm sd 比 |
  |---|---|---|---|---|
  | 原稳健 Laplace IS | 762–814 s | 0.22–0.44 | ~0.76 | 0.71–0.78 |
  | 整体放宽 2.5 倍、t 自由度 3 | 744–818 s | 0.36–0.37 | 0.71–1.03 | 0.65–0.71（ESS 掉到 ~20） |
  | 自适应 IS（2 轮，按加权协方差加分量） | 839–939 s | 0.15–0.20 | 0.64–1.00 | 0.77–0.81 |
  | Laplace + 回火（RW） | 1780–1863 s | 0.10–0.19 | 0.76–0.81 | 0.70–0.78 |
  整体放宽把数据定得很准的方向也放宽了，浪费样本；自适应 IS 第一轮 ESS 太低（3–27），估出的协方差噪声大；
  回火只有 3 个阶段、约 15 步随机游走，粒子来不及沿山脊铺开。
  **只沿弱方向放宽**（Gauss-Newton 协方差方差最大的 2–3 个特征方向放宽 2.5 倍，`--ridge`）也没用：m0 / Δm sd 比
  0.72–0.81 / 0.61–0.71，ESS 降到 40–69——山脊是弯的，局部切线方向覆盖不到它弯出去的两端，这是局部梯度信息的固有局限。

  **两阶段（`--wide 4096`）**：先做稳健 Laplace IS（1024），用它的加权均值和协方差（全局，但偏窄）放宽 2 倍、
  t 自由度 3（+5% 先验）作第二阶段提议，再抽 4096 个。3 个种子，对照宽提议参考：

  | 方法 | 用时 | 最大均值偏差 | φ / m0 / Δm sd 比 |
  |---|---|---|---|
  | **两阶段 Laplace → 宽 t** | **1244–1361 s** | **0.09–0.18** | 0.85–0.88 / 0.80–0.85 / 0.79–0.87 |
  | 原稳健 Laplace IS | 762–814 s | 0.34–0.50 | 0.84–0.91 / 0.75–0.76 / 0.73–0.80 |
  | Laplace + 回火 | 1780–1863 s | 0.23–0.24 | 0.81–0.85 / 0.76–0.81 / 0.72–0.79 |
  | 回火 SMC-RW 512 × 5（不用梯度） | 2745 s | 0.91 | 0.99 / 0.88 / 0.96 |

  两阶段方案比 SMC-RW 快约 2.1 倍、均值准得多，山脊方向的不确定度仍低估约 15%（第二阶段 ESS 93–183，
  低 ESS 下的加权方差估计本身偏小，也可能仍未完全覆盖弯曲部分）。**取舍**：梯度方法均值准、快，不确定度略窄；
  随机游走均值偏得多，不确定度大致对。需要可靠不确定度时，可把两阶段结果作为起点再做少量回火，或加大第二阶段样本。
- 启示：高维时关键不只是维数，而是参数化方式；Gauss-Newton 矩阵的特征方向（弱可辨识方向）可以用来自动发现
  更好的参数化——这一步本身就依赖梯度。

**这一轮的结论**：梯度方法的优势随维度升高**缩小**了，而不是像"随机游走在高维更吃力"那样简单地扩大——
决定性因素是后验的形状（弯曲山脊、弱可辨识）和梯度的单步成本。要在高维重新获得优势，需要：
（1）更便宜的反向梯度（按需停止的时间循环、更少的重算），（2）能适应弯曲几何的方法（按位置变化的度量，如
Riemannian MALA / HMC，或先做重参数化，例如用 m_crit − m0 代替 m_crit），（3）或者参数多到随机游走完全走不动
（空间分布的参数场）——而那时后验在多数方向上又往往只剩先验（Montecito 的 twin 反演）。

## 局限（决定这些结论能推广多远）

- 第一、二轮的后验单峰；第三轮在真正的双峰问题上测试后，Laplace 类方法的边界见上一节。
- twin 实验、无模型误差、只有 3 个参数。第二轮已覆盖 5 个采样种子和 3 组噪声实现；IBIS 各只跑了一次。
- 梯度可靠性是前提：这是在修复包 README 第 13 条（薄快前锋的孔压正反馈）之后才成立的；
  修复前，真值附近一半参数点的雅可比爆炸到 1e4–1e19，任何基于梯度的方法都会失败。
- MALA 的梯度成本有优化余地（`inference.py` 里多算了一次前向、批量较小），但即使降到 6 倍前向也仍慢于 RW。
- IBIS 只同化静态参数；模型是确定性的，所以没有"状态噪声"，也就不是带状态的粒子滤波。
